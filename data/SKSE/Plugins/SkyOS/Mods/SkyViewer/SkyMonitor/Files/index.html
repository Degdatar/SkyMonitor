Measurement note

Windows measures Skyrim.exe as one process. It cannot reliably divide CPU, GPU, or memory use among SKSE DLLs or ESP/ESM plugins. SkyMonitor reports process metrics and lists plugins separately; it does not claim per-plugin resource use.

FPS and Papyrus script totals are not currently available through the supported SkyOS telemetry interface.

Controls

SkyMonitor refreshes while its page is open. Adjust the refresh interval and plugin-list visibility in the SkyMonitor module settings. Use the SkyViewer module tab to change its global open key.
