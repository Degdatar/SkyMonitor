SkyMonitor

Track Skyrim process CPU time and memory, inspect loaded plugins, and run optional live profiles with controls in SkyViewer.

What it does

Runtime overview

SkyMonitor samples Skyrim.exe CPU time and working-set memory while the page is open. It also lists the game plugins loaded in the current session.

GPU engine utilization and dedicated video memory are shown when Windows performance counters expose them for the Skyrim process.

Measurements and limits

Why there is no per-plugin CPU chart

SKSE plugins and game plugins run inside Skyrim.exe. Windows reports resource usage at the process or GPU-engine level; it cannot attribute CPU, GPU, or memory allocations to each plugin. SkyMonitor lists plugins separately and labels resource use as shared process data rather than inventing per-plugin numbers.

FPS and average frame time come from the game frame counter. Loaded Papyrus script totals are not exposed through this telemetry API. Optional Live Profiler mode samples native CPU instruction addresses with Windows kernel ETW and groups them by loaded DLL; sample share is an estimate, not exact CPU time. ETW requires the Windows Profile system performance privilege. SkyMonitor tries to enable it for the current process; if Windows has not granted it to your account, an administrator must assign that user right and you must sign out and back in. An elevated launch may help. Another tool may already own the single NT Kernel Logger session. Stop profiling when finished.

SkyViewer options

Adjust the monitor

Open SkyViewer → SkyMonitor to set the refresh interval and toggle the loaded plugin list. The module also documents an open-hotkey preference, subject to SkyOS hotkey integration support.

Refresh interval: 1500–5000 ms. The field accepts typed values within its displayed minimum and maximum; shorter intervals use more resources.Live load order
Troubleshooting

Missing GPU or VRAM values

Some Windows driver versions do not publish the English GPU Engine or GPU Process Memory counters. CPU and RAM can still be reported. If CPU is blank immediately after opening, wait for the next sample.

Use Live Profiler carefully

Start a profile

  1. Open the SkyMonitor page and choose its explicit profiler action.
  2. Collect a short sample while reproducing the behavior you want to inspect.
  3. Stop the profile and review or export the generated report.

Windows permission requirements

ETW profiling requires the Windows Profile system performance privilege. SkyMonitor attempts to enable it for the current process. If Windows has not granted the right, an administrator must assign it to your user and you must sign out and back in. Another profiler may already own the single NT Kernel Logger session.

Module settings and limits

Refresh interval

In SkyViewer → Modules → SkyMonitor, choose a typed value from 1500 to 5000 ms. Shorter intervals refresh more often and use more resources. The default is 2000 ms.

Plugin list and hotkey

Use the module options to show or hide the loaded plugin list and configure the open hotkey. Changes apply to SkyMonitor's page, not to Skyrim's plugin loading order.

Attribution limits

Windows exposes these counters at process, GPU-engine, or module-sample level. It does not report exact CPU, GPU, or memory use for each game plugin, and this telemetry interface does not provide loaded Papyrus script totals.

Missing data

Wait for the next sampling interval if a value is blank immediately after opening. GPU or VRAM counters may be unavailable on some Windows driver versions; CPU and memory measurements can still work.

Profiling is opt-in: SkyMonitor's ordinary live dashboard does not require a deep ETW capture. Stop profiling when you have the sample you need.
